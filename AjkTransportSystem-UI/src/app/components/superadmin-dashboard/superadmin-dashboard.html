🔒 Audit Log Security Rules

  • Immutable: Logs are append-only. There is no update or delete endpoint.
  • Access Control: Only Super Admins can read the full audit log. Organization Admins can only see their organization's slice.
  • Failures Recorded: Failed actions (e.g. failed logins, blocked deletions) are logged alongside successes.
  • Protected: The audit log is protected from deletion even by Super Admins. It requires a server-level command to purge old records.
